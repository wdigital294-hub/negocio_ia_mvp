# Negócio IA — MVP

Um pequeno sistema web para comerciantes controlarem produtos, stock e vendas.

## 1. Instalar Python
Python 3.11+ recomendado.

## 2. Criar ambiente virtual

Windows:
```bash
python -m venv .venv
.venv\Scripts\activate
```

Linux/macOS:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3. Instalar dependências

```bash
pip install -r requirements.txt
```

## 4. Executar

```bash
python app.py
```

Abra no navegador:
http://127.0.0.1:5000
